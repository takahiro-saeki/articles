LAPRASのポートフォリオ、GitHub連携などの自動集計部分は勝手に埋まる一方で、職務経歴・職務要約・スキルの手入力欄をずっと空のまま放置していました。私の場合、キャリア約12年分の経歴を今さら手で入力し直す気力がなく、そのままになっていた形です。

LAPRASが公式MCPサーバーを公開していると知ったので、Claude Codeに繋いで手持ちのスキルシートから一括整備してみたところ、放置していた項目が1時間ほどで埋まりました。職務経歴17件、スキル19件、職務要約、キャリア志向まで全部です。この記事はその手順と、やってみて分かった注意点のメモです。

## LAPRAS MCP Serverでできること

公式リポジトリはこちらです。

https://github.com/lapras-inc/lapras-mcp-server

提供されているツールは大きく4系統あります。

- 職務経歴の取得・追加・更新・削除
- 経験技術(テックスキル)の取得・更新
- 職務要約とキャリア志向(やりたいこと)の取得・更新
- 求人の検索・詳細取得

つまりCareerページの手入力欄は一通りAPI経由で読み書きできます。逆に、GitHubやQiitaから自動集計される部分やスコアはMCPの対象外です。

## セットアップ

APIキーを https://lapras.com/config/api-key で発行して、Claude Codeに登録します。

```bash
claude mcp add lapras -s user -e LAPRAS_API_KEY=<キー> -- npx -y @lapras-inc/lapras-mcp-server
```

`-s user` を付けるとユーザースコープになり、どのプロジェクトから開いても使えます。

1つハマった点として、MCPサーバーの登録はセッション起動時に読み込まれるため、**起動中のセッションの途中で登録してもツールは生えてきません**。登録したら新しいセッションを開き直してください。私はここに気付かず、しばらく首をかしげていました。

## 実際にやったこと

やったことは単純で、Claude Codeに材料を渡して書き込ませただけです。

1. 現状確認: 職務経歴・職務要約・スキルを全部取得させる(私の場合、経歴1件以外すべて空でした)
2. 材料を渡す: スキルシート(Google Sheets)とポートフォリオサイトのURLを共有して読ませる
3. 登録内容の組み立て: 経歴ごとの説明文、スキルの経験年数リスト、職務要約のドラフトを作らせる
4. 一括書き込み: 経歴17件を作成、スキル19件と職務要約・キャリア志向を更新

3と4の間で一度ドラフトを確認しています。これは強くおすすめします。理由は次の節で。

## 注意点

### 更新系ツールは本番プロフィールを直接書き換える

ステージング環境のようなものはなく、update系ツールの実行結果はそのまま公開プロフィールに反映されます。書き込みの前に必ずドラフトを見せてもらう運用にしておくと安心です。プロンプトに「更新は私が承認してから1項目ずつ実行して」と一文入れておくだけで十分機能します。

### 事実は資料から。AIに経歴を「創作」させない

職務経歴はいわば公開される履歴書なので、事実でないことが書かれるのが一番まずい。私は在籍期間・社名・使用技術がすべて記載されたスキルシートを読ませて、そこにない情報は書かないよう指示しました。スキルの経験年数もシートの記載に準拠させて、記載がない技術(単体の経験年数が分からないもの)は登録を見送っています。

### 人間が読んで違和感がないか最後に確認する

一括登録の後、LAPRASのCVページを自分で読み直して、表現やまとめ方を数カ所直しました。AIに書かせた説明文は事実として正しくても、自分の言葉と微妙に違うことがあります。最終チェックだけは人間の仕事です。

## やってみた感想

正直、この作業を手でやっていたら丸1日かかっていたと思います。17件の経歴それぞれに説明文を書くのは、想像するだけで後回しにしたくなる作業です。

一方で、AIがやったのは「資料の内容をLAPRASのフォーマットに流し込む」ことであって、キャリアの中身そのものは私のスキルシートに書いてあったことです。元になる資料(スキルシートや職務経歴書)を持っている人ほど、この方法の恩恵が大きいと思います。

ついでに求人検索ツールも試しました。「TypeScript・フルリモート・業務委託」で絞ると8件ヒットして、タグや単価レンジ付きで返ってきます。言語・ポジション・稼働形態などをパラメータで指定する作りなので、Claude Codeとの対話で「もう少し単価の高い案件だけ」のように絞り込んでいけます。プロフィール整備が終わった後の案件探しフェーズでも使えそうです。
